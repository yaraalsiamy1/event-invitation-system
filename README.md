# نظام إرسال دعوات المناسبات وتأكيد الحضور بـ QR Code
> **Event Invitation & Unique QR Entry System**

نظام ويب حديث وفخم لإدارة دعوات المناسبات (أعراس، حشود، مؤتمرات) يتيح رفع كرت الدعوة، إضافة واستيراد أرقام جوالات المدعوين، وإرسال روابط مخصصة عبر واتساب تتيح للضيف قبول أو الاعتذار عن الدعوة، وتوليد تذكرة رسمية بـ **رمز QR / باركود مخصص للدخول** مع واجهة خاصة لبوابة الدخول لفحص الرموز وتأكيد الحضور.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **لوحة التحكم وإدارة المناسبة (Organizer Dashboard)**:
   - رفع وتحديد كرت الدعوة وتفاصيل المناسبة (العنوان، التاريخ، الوقت، موقع قوقل ماب).
   - إدخال واستيراد دفعة من أرقام الجوالات والأسماء بكبسة زر.
   - إحصائيات حية فورية: إجمالي المدعوين، تأكيد القبول، المعتذرين، بانتظار الرد، الحضور بالقاعة.
   - إرسال الدعوات بنقرة واحدة عبر روابط WhatsApp المباشرة (`https://wa.me/...`).

2. **بوابة المدعو التفاعلية (Guest RSVP Portal)**:
   - عرض فخم لكرت الدعوة والترحيب المخصص باسم الضيف.
   - خيارات الإجابة: **"قبول الدعوة"** (مع اختيار عدد المرافقين) أو **"اعتذار"**.
   - **توليد تذكرة دخول فريدة بـ QR Code** فور القبول مع تأثيرات الاحتفال (Confetti Fireworks) وإمكانية حفظ البطاقة للجوال.

3. **جهاز ماسح البوابة (Gate Check-in Scanner)**:
   - مسح رموز الـ QR عبر كاميرا الجهاز مباشرة أو إدخال كود التذكرة/رقم الجوال يدويًا.
   - تأكيد دخول الضيف ومرافقيه وتنبيه صوتي (Audio Chime).
   - **منع التكرار**: تنبيه فوري باللون الأحمر حال محاولة استخدام التذكرة أكثر من مرة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **HTML5 & CSS3 Vanilla**: نظام تصميم عربي فاخر (Royal Gold Theme)، مع دعم الشاشات المظلمة وتأثيرات Z-Index و Glassmorphism.
- **JavaScript (ES6+)**: برمجة المنطق التفاعلي وتحديث حالات المدعوين وحفظ البيانات محليًا (`LocalStorage`).
- **QRCode.js & Canvas Confetti**: لتوليد الرموز المشفرة ديناميكياً وإضافة التأثيرات التفاعلية.
- **HTML5-QRCode**: لمسح الـ QR Code مباشرة من كاميرا البوابة.

## 🚀 تشغيل المشروع (Running Locally)

1. قم بفتح مجلد المشروع.
2. يمكنك تشغيل المشروع مباشرة بالضغط على ملف `index.html` في أي متصفح، أو تشغيل خادم محلي:
   ```bash
   python -m http.server 8080
   ```
3. افتح المتصفح على: `http://localhost:8080`
